## 日本語

**アプリ名**（30 文字以内）

```
おでんつんつん
```

**簡単な説明**（80 文字以内）

```
見た目じゃ煮え具合がわからない！おでん屋になって、串でツンツン確かめながら、注文のおでんを煮えたそばからお客さんに出そう。
```

**詳しい説明**

```
コンビニのおでん什器を、真上からのぞいたお店。
カウンターには 6 人のお客さんがずらり。次々と注文が入り、具が鍋に入っていく。
でも、おでんは煮えても見た目が変わらない――頼りになるのは、串でツンツンした手ごたえだけ。

■ 串でツンツン、煮えていたら提供
・仕切りをタップすると、串でツンツン。注文が入っていて煮えていれば、キラッと光ってお客さんへ
・まだ煮えていなければ「まだ固い…」。注文のない具は「注文なし」
・同じ具は 1 秒以上あけてツンツン。つつきすぎると無効になって、やり直し

■ 見た目では、わからない
・大根、たまご、ちくわ、こんにゃく、はんぺん、厚揚げ、牛すじ、ロールキャベツの 8 種類
・具ごとに煮える時間が違い、しかも毎回少しずつずれる
・いつ、どの具を入れたか。覚えておくほど、うまくさばける

■ 3 段に重なる鍋
・鍋は 2 行 3 列の 6 つの仕切り。それぞれ 3 段まで、最大 18 個入る
・ツンツンできるのは一番上の具だけ。下の段は隙間からちらりと見える
・鍋が満杯になると、新しい注文は受けられない

■ お客さんを待たせるな
・待たせすぎると、お客さんは怒って帰り、評判（♥）が下がる
・ハズレのツンツンを見たお客さんはイライラ。待ってくれる時間が短くなる
・♥ が 3 つ無くなると閉店

■ うまくさばいて、売上アップ
・続けて出すとコンボボーナス、早く出すほどチップがはずむ
・営業時間は 150 秒。後半ほどお客さんが増えて、注文も多くなる
・ベスト売上を目指そう

■ その他
・開店時は、煮えた具が 6 つ仕込み済み。最初のお客さんはそれを頼んでくれる
・評判が尽きても、広告を見れば ♥1 で営業を続けられる（1 ゲーム 2 回まで）
・売上を友だちにシェア
・ポップな BGM と、具ごとに違うツンツンの音
・オフラインでも遊べる（広告・シェアは通信が必要）
・日本語・英語対応

さあ、開店。見た目にだまされず、煮えたおでんを見抜けるか？
```
