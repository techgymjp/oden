# おでんつんつん

見た目では煮え具合がわからない、おでん屋さんのWEBゲーム。

`index.html` をブラウザで開くだけで遊べます（ビルド不要・依存なし）。

## ルール

- 開店時、鍋の6つの仕切りには、ランダムな具が1つずつ**煮えた状態で**仕込んであります。開店と同時に座る最初のお客さんたちは、この6つをちょうど分け合って注文するので（その分は新しく鍋に入りません）、開店直後はどの仕切りもすぐ提供できます。
- カウンターは6席。開店と同時に満席。お客さんは1人2〜4品を注文し、その具は**空の仕切りから優先して**入り、空きが無ければランダムな仕切りの一番上に重なります。
- 席が空くとすぐ次のお客さんが座ります。来店間隔は2秒→1秒と後半ほど速くなります。
- 鍋は 2行×3列 の6つの仕切り。各仕切りは3段まで重なり、最大18個入ります。
- 鍋は上から見た視点。一番上の具は中央に、2段目は左上・3段目は右下に少しずれて、**隙間から見えます**（同じ具が重なると見分けにくいことも）。ツンツンできるのは一番上の具だけです。
- ツンツンすると具がぷるんと揺れ、具ごとに違う音がします（見た目と同じく、音でも煮え具合はわかりません）。
- 具材ごとに煮えるまでの時間が違い（さらに ±25% のばらつきあり）、**煮えても見た目は変わりません**。
- 仕切りをタップして串でツンツン。
  - 注文があり、煮えていれば → 提供（売上＋）
  - 煮えていない → 「まだ固い…」
  - 注文が入っていない具 → 「注文なし」（無効）
- 連打防止：**同じ具は1秒以上**あけないとツンツンできません。早すぎると無効になり、待ち時間もリセットされます。
- ハズレのツンツンにはペナルティがあります。見ているお客さん全員がイライラして（💢）、待ってくれる時間が減ります：「まだ固い」は0.2秒、「注文なし」「つつきすぎ」「からっぽ」は0.7秒。適当な連打では勝てません。
- 連続で提供するとコンボボーナス（1コンボごとに+¥20、最大+¥200）。早く出すほどチップが増えます（1品あたり最大¥150）。
- お客さんを待たせすぎると怒って帰り、評判（♥）が減ります。その注文の具は鍋に残り、後で同じ具を頼んだお客さんに出せます。
- 鍋が満杯（18個）になると「鍋が満杯！ 注文を受けられません」と表示され、空きができるまで新しい注文は入りません。
- 営業時間150秒、または♥が0で終了。
- 結果画面からシェアできます（スマホは共有メニュー、PCはクリップボードにコピー。𝕏 へのポストボタンも）。
- 日本語／英語に対応。ブラウザの言語で自動選択し、右上の「EN／日本語」ボタンで切り替えられます（URL に `?lang=en` でも指定可）。
- ポップなBGM付き（終盤ほどテンポアップ）。右上のボタンで消音できます。

## 確認用モード
